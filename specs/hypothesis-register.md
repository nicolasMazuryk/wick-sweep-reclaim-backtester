# WSR hypothesis register (H0–H12) — thresholds fixed before any data is seen

Fixed on 2026-09-19, before any archive was downloaded. Changing a threshold, a slice or a grid after
this date is a plan deviation and must be written into the phase memo (`runs/<runId>/MEMO.md`) and
into the "post-hoc observations" appendix of `specs/research-plan.md`; it never enters the verdict.

Conventions. "CI" = 95 % volume-day block-bootstrap CI as produced by the harness (B = 2000 for
reaction / fold metrics, B = 1000 for the reality check). "OOS" = pooled test windows of the
walk-forward (`folds.json` entry `foldId: "pooled"`, `window: "test"`). "≥ 75 % of folds" = the
harness's `CONSISTENT_SHARE` (report Q3/Q4). `CLI` = `node packages/cli/dist/main.js`. Span =
`--from 2025-09-18 --to 2026-09-18` unless stated. All configs live in `configs/research/`
(index: `configs/research/README.md`). Report sections are those of `runs/<runId>/report.md`
(`packages/backtest/src/report.ts`, §0–§12). Prompt refs: strategy.md = S, implementation spec = I.
